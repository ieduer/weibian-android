# 美术资产体系

设计资产与代码分开管理：**源文件放这里，产物才进 `app/src/main/res/`**。

```
art/
├── icon/      应用图标源文件
├── badges/    段位与成就徽记
└── source/    可编辑源（SVG / 设计稿）
```

## 授权

**本项目全部美术资产为原创矢量绘制，无任何第三方素材、字体或图片。**
随代码以 MIT 授权（见根目录 `LICENSE`）。

未使用、也不得使用：任何游戏（含《第五人格》）的美术素材、图标、字体或音效。
游戏化设计只借鉴**机制**（段位递进、成就反馈、收集、赛季驱动），不借用任何视觉资产。

## 已产出

| 资产 | 位置 | 说明 |
|---|---|---|
| 应用图标 | `app/src/main/res/drawable/ic_launcher_foreground.xml` | 自适应图标前景：以皮绳编连的竹简（韦编三绝），五简两绳，简上墨痕示意文字 |
| 图标底色 | `app/src/main/res/values/ic_launcher_background.xml` | 宣纸暖白 `#F7F3EA` |
| 单色图标 | 同前景 | 已声明 `<monochrome>`，支持 Android 13+ 主题化图标 |

图标为纯矢量（VectorDrawable），无位图，任意密度清晰，深浅色壁纸下均可读。

## 色板

取宣纸与墨，朱砂点睛。定义在 `ui/Theme.kt`。

| 名称 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| 宣纸 / 靛夜 | `#F7F3EA` | `#14161B` | 底色 |
| 松烟墨 / 暖字 | `#1C1A17` | `#ECE5D8` | 正文 |
| 朱砂 | `#A8322A` | `#C8524A` | 强调、印章、段位、注释标记 |
| 青瓷 | `#5C7F72` | `#86A99C` | **答对**、已读状态 |
| 藤黄 | `#B8862B` | `#D9AC57` | 成就、段位星 |

**朱砂不可用于表示"正确"** —— 它与错误色几乎同色，对错状态会分不开。
正确一律用青瓷绿。这是实测踩过的坑，见 `docs/DEVELOPMENT.md`。
